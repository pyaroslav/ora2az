# ora2az — an Oracle → Azure migration knowledge graph on Sanity

Two DEV.to Sanity Challenge entries share this dataset:

- **agent/** — Path One. A migration advisor that runs on a headless agent CLI and answers only from the structured content behind two Sanity Context MCP endpoints (GROQ + Knowledge Base), with an eval against a keyword-search baseline.
- **app/** — Path Two. *Legacy Obituaries* (live: https://ora2az.vercel.app): an obituary page for every Oracle feature that is desupported or has no clean Azure home, generated from the same graph.
- **desk/** — App SDK review desk for certifying obituaries.
- **studio/** — Sanity Studio and schema (hosted at https://ora2az.sanity.studio, Sanity login required; the dataset itself is public). **content/** — YAML source of truth + seed script.

Sources are public only: Oracle docs, Microsoft Learn, community docs, and my own public blog and labs. Every claim in the dataset carries a source document.
